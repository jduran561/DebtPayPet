# DebtPayPet

A personal project I'm building to help track and pay off debt, with a virtual pet twist to make the journey more engaging.

## About

DebtPayPet is a debt tracking application that gamifies the debt payoff process. As you make payments and reduce your debt, your virtual pet grows and evolves with you.

## Features

- Track multiple debts (credit cards, loans, etc.)
- Choose between debt payoff strategies (avalanche, snowball)
- Virtual pet that responds to your progress
- Visual debt summary and progress tracking

## Tech Stack

- React
- TypeScript
- Vite
- Zustand (state management)

## Getting Started

```bash
npm install
npm run dev
```
